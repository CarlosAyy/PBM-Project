This Monte Carlo simulation, utilizing MatLab, has a multitude of factors that are easily adjustable to measure across any sample of tissue given the right geometrical parameters. This customization ranges from the wavelength of the light source to the temperature flexibility and how effective the heat and photon distribution across the medium can be displayed via color mappings and graphs. There's even a toggle within the code to enable/disable bio-material to further investigate the distribution of heat and photons too. 

Listed of GitHub references for each parameter of base code:
